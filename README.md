# ATLAS

Assistente pessoal inteligente com IA local, desenvolvido em Java, com integração de voz, automação de tarefas e modelos locais via Ollama.

## Sobre

A ATLAS é um projeto de assistente pessoal inspirado em conceitos como Jarvis, com foco em:

- Inteligência artificial local;
- Controle do sistema;
- Interface gráfica JavaFX;
- Reconhecimento de voz;
- Automação de tarefas;
- Memória persistente.
